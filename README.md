# Fridge to the Future

The steam-powered refrigerator Doc Brown builds in 1885 in _Back to the Future Part III_, as an
interactive, full-page, cell-shaded 3D scene. Start the engine, wait for the whistle, turn the
valve all the way to the left... and get your single ice cube.

## Getting started

```sh
nvm use
make install
make start   # http://localhost:1885
```

`make help` lists every command; `make check` runs the whole quality gate.
